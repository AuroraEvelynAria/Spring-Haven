Spring Haven Playtest
======================

启动
----
双击 SpringHaven.exe。Companion Core 会由游戏自动启动，不需要另开命令行。

首次进入时，如果尚未配置聊天模型，主菜单会打开“AI 模型”设置。填写你自己的
OpenAI-compatible Base URL、模型名和 API Key 后保存；Key 由当前 Windows 用户的
DPAPI 加密保存，不会写进游戏目录或回显到界面。

当前测试重点
------------
1. 从主菜单“📚 旅程档案”新建两个命名旅程，切换后确认聊天、角色和属性互不覆盖；
   再测试重命名、归档与恢复。归档只隐藏入口，不删除文件或记忆。
2. 点名小玲或小奈时是否由正确角色回答。
3. 双人回答是否保持顺序，第二位是否看得到第一位刚说的话。
4. “让小玲去问小奈”一类转述是否保留正确的发起者和目标。
5. 跨天聊天、心织记忆召回和知识库角色作用域是否正确。
6. 团子生活实验室中的跟随、寻路、生活互动和角色间对话是否稳定。
7. 长时间后台运行后，主动消息、Windows 通知、资源占用和恢复能力是否正常。
8. 用“陪你去散步”“去上厕所吧”“帮你处理伤口”“一起玩游戏吧”等明确表达时，
   对应角色属性是否变化；否定、疑问、假设、引用、代码和网址不应误触发。
9. 点击聊天页顶部的“🕸️”打开记忆网络，检查节点拖动、画布缩放、角色筛选、搜索、
   关联强度滑杆和右侧关联记忆详情是否正常。

自然语言互动支持轻度与强度表达，例如“轻轻抱抱你”变化较小，“紧紧抱抱你”变化较大。
每个角色、每种动作的基础变化量仍可在“设置 → 高级 → 互动数值”中单独调整。生育力与着床率
由经期系统计算，不接受普通聊天文本直接覆盖。

旅程档案中标记“部分恢复”的旧旅程来自历史聊天归档：聊天和同 save_id 的心织记忆仍可
继续使用，但历史上已经被旧单槽覆盖的属性和生活日程无法精确重建，因此采用当前默认值。

日志
----
设置 → 高级 → 可靠性中可以点击“生成脱敏诊断包”。默认
诊断包只包含运行状态和日志文件清单，不包含日志正文、聊天、Persona、知识库、数据库
或 API Key。反馈启动失败、网络错误或设置异常时，优先附上这个诊断包。

Godot 日志：%APPDATA%\Godot\app_userdata\Spring Heaven\logs
Core 日志：%APPDATA%\Godot\app_userdata\Spring Heaven\companion-core\logs

如果主菜单提示“Companion Core 未启动”，先确认压缩包已经完整解压，并检查 Windows
安全中心是否隔离了 companion-core\bin\spring-haven-core.exe。

隐私与内容
----------
聊天记录、数据库、知识库和模型密钥默认只保存在当前电脑。公开试玩模板默认关闭
成人内容；成年用户可在“设置 → AI 服务 → 对话模型 → 对话内容边界”确认年龄并开启。
此开关只适用于全部角色均已配置为成年人的情况。发行包不包含开发者本机数据库、
知识文件、密钥或无分发许可的占位角色模型。

这是未签名的内部试玩构建。Windows 可能显示未知发布者提示；正式发行前会加入代码
签名、安装器、崩溃报告授权开关和有明确分发许可的正式美术资源。
