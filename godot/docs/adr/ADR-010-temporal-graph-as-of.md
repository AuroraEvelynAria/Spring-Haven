# ADR-010: 心织图谱时间游标(Temporal Graph / as_of_world)

- 状态:已批准(2026-09-27,用户确认实施)
- 关联:ADR-001(检索与记忆网络)、ADR-009(实体-主张层);外部参照:AIRI 协作讨论中的「4D Mind Timeline」构想
- 前置:schema v6+ 的 world_time 单时钟(本 ADR 的时间游标即世界天)

## 背景

心织记忆网络的每条记忆(`world_created_at`)与每条边(`memory_links.world_created_at`)都带世界日时间戳——这是本项目被 AIRI 开发者特别认可的设计。在此基础上把图谱变成「时间机器」:把游标拨回过去,只渲染那一刻已存在的心智;拨回现在,看到全部。数据层(v6/v7/v8)已全部就绪,本 ADR 只定义查询契约与客户端交互。

## 决策

### D1 `/heartloom/graph?as_of_world=<世界天>`

- `as_of_world` 缺省/空 → 实时态(行为与现状完全一致);给定 →:
  - 节点:`world_created_at <= as_of_world`(该时刻已诞生的记忆);
  - 边:`memory_links.world_created_at <= as_of_world`(该时刻已建立的关联);
  - `lifecycle='active' AND enabled=1` 的现有硬过滤保持不变(时间游标回答「心智何时长大」,生命周期回答「现在还信不信」)。
- 非法值(负数/非数字)→ 400,与分页参数同级校验。
- 响应新增三个字段供客户端取值:
  - `as_of_world`:本次实际使用的游标(无则 null);
  - `world_now`:服务端当前世界日(滑杆"现在"端点);
  - `world_range`: `{earliest, latest}` —— 全库最早/最晚世界日,**不受 as_of 影响**(滑杆量程必须恒定,否则拖动时会自己缩放)。
- 分页语义不变:`truncated`/`cursor` 基于 as_of 过滤后的集合计算。
- 精度说明:world_now 在响应中四舍五入到 4 位小数(≈0.14s),客户端把游标拨到"现在"端点时对该值加少量余量或直接省略 as_of 参数即可看到全量。

### D2 客户端(Godot 🕸️ 面板):时间滑杆

> **2026-09-27 二次修订(用户反馈后)**:首版滑杆"拖动结束→带 as_of 重新请求"被否——
> 每拖一次就重新请求 + 重排布局,既不平滑又让节点反复运动。修订后的交互:
>
> - **始终加载全量图谱**(面板 limit 提到 200),拖动滑杆**零请求、零重排**;
> - 画布新增 `set_time_cursor(世界日)`:按 `world_created_at` 把游标之后诞生的
>   节点降为低亮度半透明幽灵(α≈0.14,无高亮/无标签/无高光),游标之后建立的
>   边(边 payload 自带 `world_created_at`,D1 补充)降为 α≈0.05 的"将成形"结构;
> - **亮度带时间插值**(用户反馈"没有平滑过渡"后补):每节点/边的幽灵程度
>   在 `_process` 里按帧率无关的指数趋近逐帧逼近目标(速率 9/s,约 0.25s 到位),
>   `_draw` 消费动画量 —— 拖动滑杆时节点/边的亮暗是连续渐变,不是二值跳变;
>   布局全程不变,选中等交互在点亮度过半后才生效;
> - 布局全程不变 —— 力导向位置在拖动期间纹丝不动,只有亮度跟随滑杆;
> - `as_of_world` 服务端过滤保留,供 API 消费者做"快照式"查询;面板不再使用。
>
> 首次加载仍用 `world_range`/`world_now` 校准滑杆量程(earliest→world_now,
> step = 0.5 世界日);"现在"按钮 = 游标置 -1(全亮),不发请求。

### D3 明确不做(负面清单)

- 不做实体-主张节点进图(v8 数据已可支撑,但图契约要加节点类型系统,留给实体星座图专项);
- 不做生命周期状态的时间回放(`lifecycle_changed_world` 可以支持"当时是否休眠"的近似,暂不引入复杂度);
- 不改 v1 遗留 `/memory/graph`(已处于废弃轨道,ADR-001 D7)。

## 后果

- 正面:心智生长可视化成立——滑杆拨回第 1 天,图上只有最初几条记忆;拨回现在,全部浮现。对照 4D 构想的"Herbal Essences 某刻诞生"效果,记忆块层先落地。
- 代价:`graph_page` 每次多一次 MIN/MAX 查询(可忽略);滑杆引入新的请求路径(拖动结束才请求,量级不变)。
- 验收:① as_of 过滤节点/边(含增量建边时序);② world_range 恒定;③ 非法值 400;④ 全量 CI 绿;⑤ Godot 滑杆手动验收。
