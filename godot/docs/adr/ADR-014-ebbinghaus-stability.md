# ADR-014: 艾宾浩斯正式化(intrinsic 稳定度系数与方向修正)

- 状态:已批准(2026-09-28,用户确认"三块差距全部实施"后的排队项)
- 关联:ADR-001(双参数衰减与唤醒奖励)、ADR-013(夜织);外部参照:艾宾浩斯遗忘曲线 / FSRS 的稳定度-可提取性模型、AIRI 对比表「Wake Rewards: decay shield」
- 前置:schema v10(存量 intrinsic 倒数重映射),无新表

## 背景

ADR-001 引入双参数衰减时说好了「intrinsic 越高衰减越慢」(唤醒奖励=衰减护盾,AIRI 对比表亦如此对外描述),但实现把公式写成了 `effective_half_life = half_life / intrinsic`——**方向正好相反**:被频繁召回的记忆(intrinsic 越大)有效半衰期越短、衰减越快,护盾变成了惩罚。该矛盾从 v6 存活至今,因为没有任何测试断言过方向。

同时「每召回 +0.05、封顶 1.0」是线性奖励:增长空间小(0.5→1.0,至多两倍)、且与艾宾浩斯/间隔重复的「稳定度乘法增长」模型不符(每次成功回忆,遗忘速度应成比例变慢)。

## 决策

### D1 语义与公式(修正 + 正式化)

- `intrinsic` 正式定义为**稳定度系数**:`有效半衰期 = half_life × intrinsic`。
  - `1.0` = 标称半衰期(默认值);
  - 越高衰减越慢——护盾方向与 ADR-001 的文字描述、对外对比表一致。
- 可提取性 `R(t) = 0.5^(age_days / 有效半衰期)`,即 `recall_pool` 输出新增的 `recall_decay` 字段(R(t) 可提取性曲线,供记忆网络展示;不参与排序通道以外的用途)。

### D2 乘法稳定度增长

- 每次成功召回(含 `remember_user_turn` 的窗口内复发强化):`intrinsic = MIN(cap, intrinsic × 1.5)`。
- 上限 `WAKE_REWARD_CAP = 4.0`(护盾最多把半衰期拉长到 4 倍);1.0 → 1.5 → 2.25 → 3.375 → 4.0,约 5 次成功回忆到顶——间隔重复的收益递减由封顶体现。
- 加法常量 `WAKE_REWARD_PER_RECALL` 删除;新常量 `WAKE_GROWTH_FACTOR = 1.5`。

### D3 v10 迁移(存量无感)

- `stored_version < 10` 时:强制备份 `*.pre-v10.backup`;`intrinsic' = MIN(4.0, MAX(1.0, 1 / MAX(0.05, intrinsic)))`。
- 倒数重映射在**迁移瞬间逐条保持有效半衰期不变**(旧 `hl/i` ≡ 新 `hl×(1/i)`):旧值域 [0.5, 1.0] → [1.0, 2.0];罕见的小值(<0.25)封顶 4.0,与新上限一致。
- 新库 DDL 默认 1.0;`put_memory` 显式默认 1.0、量程 [0, 4]。
- 回滚脚本 `migrations/v10_ebbinghaus_rollback.sql`(倒数对称,同样自洽)。

### D4 明确不做(负面清单)

- 不做真实日历时间的艾宾浩斯(本系统一律世界时间,ADR-010/#23 原则);
- 不做「失败回忆/间隔长度」建模(FSRS 的 difficulty/stability 全量模型留给未来;单参数稳定度已覆盖间隔重复主效应);
- Godot 侧 R(t) 曲线绘制留作展示层后续消费(数据字段 `recall_decay` 已就绪)。

## 后果

- 正面:修复了「热情互动反被更快遗忘」的隐性惩罚;召回/复发收益变为乘法模型,与艾宾浩斯-间隔重复一致;`recall_decay` 为记忆网络提供可提取性曲线数据。
- 代价:schema v10 迁移(有备份、有演练测试);未召回记忆的衰减从「2× 标称半衰期」回到「1× 标称半衰期」,会比以前更快进入 dormant/archived 轨道——这正是「不用则忘」的正确语义。
- 验收:① 方向(120 天后 intrinsic 4.0 的 R 高于 1.0,且 1.0 处 R≈0.5);② 乘法增长与封顶(4.0);③ v10 迁移三分支(0.5→2.0 / 1.0→1.0 / 0.05→4.0)+ 备份;④ `recall_decay` 载荷;⑤ 全量 CI 绿、棘轮 0.4667 不回归(倒数重映射保等价)。
